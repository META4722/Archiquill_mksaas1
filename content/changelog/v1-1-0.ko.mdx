### 새로운 기능

우리는 당신의 경험을 개선하기 위해 몇 가지 새로운 기능을 추가했습니다 :

- **어두운 형태**: 빛과 어둠의 테마 사이 토글
- **수출 옵션**: 여러 형식의 데이터를 내보내기 (CSV, JSON, PDF)
- **고급 검색**: 향상된 검색 기능으로 더 빠르게 필요한 것을 찾아보세요.
- **사용자 정의 템플릿**: 재커링 프로젝트에 대한 템플릿 생성 및 저장

### 제품 정보

- **성능 최적화**: 감소된 페이지로드 시간 40 %
- **UI 개선**: 더 나은 접근성을 가진 상쾌한 디자인
- **모바일 경험**: 모든 장치 크기에 대한 향상된 반응형 디자인
- **알림 시스템**: 향상된 알림 전달 및 관리

### 버그 수정

- 프로젝트 복제를 통한 고정 문제
- Resolved 캘린더 동기화 문제
- 고정된 데이터 가져 오기 유효성 오류
- API 요청에 대한 향상된 오류 처리
